# Parallel Worlds - Local Development & Installation Guide

## Prerequisites
* **Node.js**: v18.0.0 or higher
* **npm**: v9.0.0 or higher

---

## Quick Start Steps

1. **Clone the Repository**:
```bash
git clone https://github.com/example/parallel-worlds.git
cd parallel-worlds
```

2. **Install Dependencies**:
```bash
npm install
```

3. **Start Full-Stack Development Server**:
```bash
npm run dev
```
* The Express backend server boots up at `http://0.0.0.0:3000` with Vite middleware mounted automatically.

4. **Verify Linter and Type Checks**:
```bash
npm run lint
```

5. **Build for Production**:
```bash
npm run build
```

6. **Start Production Container**:
```bash
npm start
```
